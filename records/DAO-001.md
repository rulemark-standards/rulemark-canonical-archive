## Abstract

This document defines the canonical governance framework for Compliant Decentralized Autonomous Organizations (DAOs).

It establishes non-discretionary structural boundaries for governance, decision-making, accountability, and upgrade control, ensuring that DAO operations remain verifiable, auditable, and compatible with institutional and regulatory environments.

This record serves as a reference standard for DAO classification, evaluation, and registry inclusion.

---

## Core Principles

1. **Rule Supremacy**  
   Governance rules precede discretion. No actor may override defined rules without a formal protocol upgrade.

2. **Structural Transparency**  
   All governance structures must be publicly documented and cryptographically verifiable.

3. **Non-Discretionary Execution**  
   Execution paths must be deterministic and auditable.

4. **Upgrade Constraint**  
   Any modification requires a new canonical record. This document itself is immutable.

## Applicability

This standard applies to:

- Hybrid protocol organizations
- AI-governed or AI-assisted organizations
